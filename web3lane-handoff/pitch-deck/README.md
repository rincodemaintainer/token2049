# web3lane pitch deck

Next.js presentation with eight evidence-led slides, local Plus Jakarta Sans and IBM Plex Mono fonts, and restrained Lucide icons.

```sh
npm ci
npm run dev
```

Open `http://localhost:3000`. Use arrow keys or the controls to change slides; `O` opens the overview. `npm run build` produces a static export in `out/`. Print from the browser in landscape with background graphics enabled for a PDF.

The older standalone `slide-*.html` files remain as a reference. The current slide source is `app/page.tsx` and `app/globals.css`. Current prototype status comes from `../../web3lane-agent/README.md`; planned and illustrative claims are labeled on the slides.
